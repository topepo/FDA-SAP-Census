# SAP Keyword Taxonomy

A controlled vocabulary for tagging FDA Phase III submissions in `census.md`. As of this writing, the census is 100% complete: all 684 FDA novel drug approvals tracked in `master_index.md` (2011 through Sept 2026) have a full SAP-depth entry in `census.md`, spanning 13 therapeutic areas (Oncology 203, Cardiovascular/Metabolic 61, Infectious Disease 83, Neurology/Psychiatry 75, Rare Disease/Genetic/Metabolic-genetic 63, Immunology/Rheumatology/Dermatology 53, Other/Misc 45, Hematology 37, Gastroenterology 20, Endocrine 20, Ophthalmology 18, Respiratory 6). This taxonomy remains a living document — if a future entry (e.g., a new approval added after this writing) uses a method not already listed, append a new row rather than creating a parallel/duplicate term. Each entry in the census carries a **Keywords:** line using these terms, grouped into the same categories as below, so entries can be filtered/grepped by method. This is a living taxonomy — as more submissions are added, new terms should be appended to the relevant table rather than creating parallel/duplicate terms for the same concept.

Short trial names used in the "Seen in" columns: KEYNOTE-024, FLAURA, SOLO-2, PREVAIL, CLL14, COU-AA-301, BRIM-3, COMFORT-I, COMFORT-II, Erwinaze, AXIS, ERIVANCE BCC, Rolapitant/HEC1, Rolapitant/HEC2, Rolapitant/MEC, PALOMA-1 (oncology / supportive-care oncology); EMPA-REG, PARADIGM-HF, DECLARE-TIMI58, FOURIER, SELECT (cardiovascular/metabolic).

## 1. Trial design

| Keyword | Definition | Seen in |
|---|---|---|
| Randomized, double-blind, placebo-controlled | Standard blinded RCT design with an inert comparator | SOLO-2, PREVAIL, EMPA-REG, DECLARE-TIMI58, FOURIER, SELECT |
| Randomized, double-blind, active-controlled | Blinded RCT with a comparator that is itself an active treatment (not placebo) | FLAURA, PARADIGM-HF, Rolapitant/HEC1, Rolapitant/HEC2, Rolapitant/MEC (add-on design: both arms received the same background antiemetics, active-comparator arm omitted only the study drug/placebo) |
| Randomized, open-label, active-controlled | Unblinded RCT against an active comparator, typically relying on BICR/IRC to limit assessment bias | KEYNOTE-024, CLL14 |
| Event-driven trial | Trial duration/analysis timing set by accrual of a target number of clinical events rather than a fixed calendar time | KEYNOTE-024, FLAURA, PREVAIL, CLL14, EMPA-REG, PARADIGM-HF, DECLARE-TIMI58, FOURIER, SELECT |
| Non-inferiority-then-superiority hierarchy | Design first rules out a pre-specified excess-risk margin, then (only if non-inferiority holds) tests for superiority | EMPA-REG, DECLARE-TIMI58 |
| Co-primary endpoints | Two endpoints each individually required (or each independently testable) to support the primary claim | PREVAIL (OS + rPFS), DECLARE-TIMI58 (MACE + HHF/CV-death, post-amendment) |
| Dual primary-endpoint definition (protocol vs. regulatory) | Sponsor's protocol names one endpoint as primary while a *different* assessment of the same construct is designated primary for a specific regulator | CLL14 (investigator-assessed PFS per protocol; IRC-assessed PFS for US regulatory purposes) |
| Mid-trial SAP amendment changing endpoint status | A secondary endpoint formally promoted (or primary endpoint's assessment method changed) after trial start, before database lock, sometimes at FDA's request | SOLO-2 (BICR→investigator primary), DECLARE-TIMI58 (secondary→dual-primary) |
| Crossover permitted at progression | Control-arm patients may switch to the experimental drug after a defined progression/eligibility trigger | KEYNOTE-024, FLAURA |
| Biomarker-selected/enriched population | Enrollment restricted to a molecularly-defined subgroup expected to benefit | KEYNOTE-024 (PD-L1 TPS≥50%), FLAURA (EGFR mutation), SOLO-2 (germline BRCA) |
| Dose-arm pooling | Two or more randomized dose arms of the same drug combined into one group for the primary analysis | EMPA-REG (10 mg + 25 mg pooled) |
| Fixed-duration regimen | Treatment given for a pre-specified number of cycles/duration rather than until progression | CLL14 |
| Early-stopped for efficacy | Trial halted before planned completion because an interim analysis crossed an efficacy stopping boundary | PARADIGM-HF |
| Single-arm, open-label trial | Uncontrolled trial with no randomized comparator, typically supporting accelerated approval on a surrogate/response endpoint | Erwinaze (Study 1), Ibrutinib (PCYC-1104-CA), Carfilzomib, Bosutinib (Study 200), Omacetaxine, Ponatinib (PACE) |
| Post-hoc recombination of differently-enrolled cohorts into one primary analysis population | A trial enrolls a first cohort under one eligibility criterion (e.g., all-comers), then switches to a differently-selected cohort (e.g., biomarker-selected) for further enrollment, and — via a data-driven SAP amendment made after an interim look at the first cohort's efficacy — pools both cohorts into a single primary efficacy population | PALOMA-1 (Part 1 all-comers + Part 2 CCND1-amplified/CDKN2A-loss biomarker-selected, pooled after an interim look at Part 1) |
| Simon's two-stage design | A named single-arm design for early-phase (typically Phase II) trials that specifies a stopping rule after a first stage of enrollment based on observed responses, before proceeding to a second stage — sometimes carried into a registration-supporting trial rather than a standalone dose-finding study | Dinutuximab, Bosutinib (Study 200, Part 1; FDA criticized its use to support an efficacy claim) |
| Diagnostic-accuracy study (single-arm, within-patient paired comparison) | Non-randomized study where every subject receives both the investigational diagnostic/mapping agent and an active comparator/reference standard, with accuracy assessed by within-patient agreement rather than between-arm comparison | Technetium Tc 99m tilmanocept/Lymphoseek (NEO3-05, NEO3-09), Fluciclovine F 18/Axumin, Gallium Ga 68 dotatate/Netspot |
| Retrospective/non-prospective diagnostic evidentiary basis (academic or literature-derived, not a company-sponsored pivotal trial) | Approval basis built from re-analysis of independently-conducted academic studies and/or published literature rather than a prospective, company-sponsored registration trial; may include an FDA-rejected sponsor meta-analysis | Fluciclovine F 18/Axumin, Gallium Ga 68 dotatate/Netspot (FDA reviewer rejected a sponsor literature meta-analysis as an inadequate regulatory basis) |
| Tumor-agnostic (tissue-agnostic) basket trial | Histology-agnostic enrollment based on a shared molecular alteration (e.g., a gene fusion) across multiple tumor types, with efficacy pooled across histologies rather than shown separately per cancer type | Larotrectinib (pooled across 3 trials), Entrectinib (ALKA-372-001 + STARTRK-1 + STARTRK-2) |
| Cross-trial pooled/integrated analysis (independently conducted, separately sponsored/protocoled trials) | Primary efficacy population combines patients from multiple independently designed and separately run trials (different phases, sometimes different sponsors/eras), as distinct from post-hoc pooling of cohorts *within* one trial | Larotrectinib, Entrectinib, Rucaparib (companion cohorts across 2 single-arm trials) |
| Randomized non-comparative dose-regimen cohort design | Randomization used only to allocate patients across two or more dosing regimens of the same drug, with each regimen analyzed independently against a fixed performance goal rather than compared to the other arm(s) — not a between-arm efficacy comparison | Brigatinib (ALTA, 90mg QD vs. 90→180mg QD regimens) |
| Adaptive seamless dose-selection-into-expansion design | An internal randomized dose-comparison stage resolved via a Data/Dose Review Committee interim analysis, after which a further single-arm expansion enrolls only at the selected dose/regimen | Erdafitinib (BLC2001, Regimen 1 vs. 2 → Regimen 3 expansion) |
| Contribution-of-components trial-part addition | A second randomized trial part/arm added mid-conduct via protocol amendment, at FDA's request, specifically to isolate and demonstrate an individual component drug's contribution to a combination regimen | Encorafenib + Binimetinib (COLUMBUS Part 2 added to address contribution-of-components concern for two simultaneously-developed, previously-unapproved drugs) |
| FDA-conducted independent expansion of the efficacy analysis population | FDA itself broadens the efficacy-evaluable population beyond the sponsor's pre-specified primary analysis set, using a later data cut and/or revised inclusion criteria, rather than the sponsor amending its own SAP | Ivosidenib (FDA broadened N from 125→153→173 across successive analyses) |
| Multi-tumor-type cohort analysis within a single genetically-defined single-arm trial | Multiple histologically distinct tumor types, unified by one shared germline/genetic alteration, are each analyzed as a separate efficacy cohort within one single-arm trial (not pooled across cohorts) — distinct from a tumor-agnostic basket trial, which pools across unrelated cancers sharing a somatic driver | Belzutifan (VHL disease: RCC, CNS hemangioblastoma, pNET cohorts) |
| Sequential-cohort dose-confirmation design with committee-driven interim stopping rules | A single-arm trial enrolls in sequential cohorts, with a Data/Study Review Committee reviewing accruing data at pre-specified patient counts and issuing stop/continue/expand decisions before further enrollment | Asparaginase erwinia chrysanthemi (recombinant)-rywn/Rylaze |
| PK/exposure-equivalence bridging study (crossover, not a fresh efficacy RCT) | Registrational evidence based on demonstrating pharmacokinetic exposure-equivalence (e.g., AUC) between a new formulation/route and an already-approved reference product, in a randomized crossover PK study, rather than a new randomized efficacy comparison | Decitabine/cedazuridine (ASCERTAIN vs. IV decitabine), Eflapegrastim (vs. pegfilgrastim, non-inferiority), Pembrolizumab/berahyaluronidase (Keytruda Qlex, subcutaneous vs. IV) |
| Regular approval supported by same-pharmacologic-class precedent as confirmatory evidence | FDA concludes substantial evidence of effectiveness from one adequate/well-controlled single-arm trial plus confirmatory evidence consisting of other already-approved drugs in the same class/target showing similarly durable response in the same indication, rather than requiring an independent randomized confirmatory trial | Repotrectinib (TRIDENT-1 plus established effectiveness of entrectinib/crizotinib as confirmatory evidence for ROS1+ NSCLC) |
| Multi-arm trial mixing a randomized comparison with a modified single-arm dose-confirmation cohort | A single trial protocol contains both a randomized/comparative arm structure and a separate non-comparative cohort (e.g., a Simon's two-stage-designed arm) enrolled in a distinct population, analyzed independently | Iberdomide-class development programs (multi-arm dose-expansion + safety cohort designs) |
| Literature-based approval (no dedicated pivotal trial) | FDA approval rests on its own review of multiple independently published randomized trials in the literature, rather than a sponsor-run pivotal trial, sometimes using a post-hoc composite endpoint constructed across the pooled literature | Landiolol (8 published RCTs) |
| Small single-arm or small randomized trial in an ultra-rare disease population | Registrational evidence from a trial with a very small sample size (often <100 patients), reflecting the ultra-rare prevalence of the treated condition | Lomitapide (29 patients, single-arm), Mipomersen (51 patients, randomized), Metreleptin, Evinacumab-dgnb (65 patients) |
| Non-inferiority analysis against a fixed historical-control threshold (no concurrent comparator arm) | Efficacy assessed by comparing a single arm's observed response rate against a fixed threshold derived from historical/literature data (not a concurrently randomized comparator), often because a placebo-controlled trial would be unethical (e.g., serious bacterial infection with limited treatment options) | Ceftazidime/avibactam (Avycaz, RECLAIM), Elbasvir/grazoprevir (Zepatier), Ombitasvir/paritaprevir/ritonavir + dasabuvir (Viekira Pak) |
| Animal Rule approval (efficacy shown only in animal models) | Approval under 21 CFR 314.610/601.91 where human efficacy trials are not ethical or feasible; substantial evidence of effectiveness instead comes from adequate, well-controlled animal-model (e.g., monkey/rabbit lethal-challenge) studies, with human data limited to safety/PK/PD | Raxibacumab, Obiltoxaximab, Tecovirimat |
| Adaptive seamless enrollment with a conditional-power enrollment gate | A trial pauses/halts further enrollment at a pre-specified interim point so an external DMC can review conditional power on an early efficacy signal before authorizing full enrollment to continue, without a formal dose- or regimen-selection decision at that gate | Ledipasvir/sofosbuvir (Harvoni, ION-1: enrollment gated on SVR4 conditional power at ~25% of planned enrollment) |
| Prospective single-center academic diagnostic-accuracy study (non-industry-sponsored) | A registrational diagnostic-accuracy trial run by an academic/investigator sponsor (not a commercial developer) at a single site, often under an expanded-access or investigator-held IND, distinct from a multi-site industry-sponsored pivotal trial | Fluorodopa F 18 (Feinstein Institute, "Study #18") |
| Approval program with a substantial proportion of negative/failed pivotal trials | Regular approval granted where FDA's efficacy conclusion rests on a subset of positive trials within a larger program that included multiple negative/failed studies, with the review explicitly separating positive from negative trials rather than pooling all of them | Vortioxetine (Brintellix, 6 of 10 short-term trials positive) |
| Retrospective natural-history/genotype-matched external-control comparison (rare disease) | Regular (non-accelerated) approval built on a comparison between a treated single-arm cohort and a retrospectively assembled external-control cohort matched on genotype and/or natural-history disease course, rather than a concurrent randomized comparator | Lonafarnib (Zokinvy), Fosdenopterin (Nulibry) |
| Staggered-entry "Blind Start" crossover design | A single-arm-appearing trial in which every subject eventually receives the study drug, but entry onto treatment is staggered/randomized in timing so that later-starting subjects' pre-treatment period serves as a within-subject/cohort untreated-comparator baseline | Vestronidase alfa-vjbk (Mepsevii) |
| Matched external-control survival analysis (ultra-rare pediatric fatal disease) | A treated cohort's survival is compared against a separately assembled, matched external-control cohort (natural-history or another data source) using a pre-specified matching algorithm, used where a concurrent placebo/comparator arm in a fatal pediatric ultra-rare disease is not ethically feasible | Doxecitine/doxribtimine (Kygevvi), Copper histidinate (Zycubo) |
| Propensity-score-weighted external/historical placebo control substituting for a concurrent placebo arm | A randomized, open-label trial with an active reference arm compares its investigational-drug arm against a placebo cohort drawn from an already-completed, separately conducted trial of a different drug in the same indication, reweighted via propensity scoring for comparability, rather than including a concurrent placebo arm | Eplontersen (Wainua) |
| Accelerated approval based on an interim analysis, confirmed by the same trial's own final analysis | Accelerated approval is granted on a surrogate endpoint from a planned interim analysis of an ongoing randomized trial, with that same trial's later final analysis (not a separate confirmatory trial) serving to verify clinical benefit | Atacicept-vymj (Trutakna) |
| Randomized-withdrawal enrichment design | All subjects first receive open-label active drug during a run-in period; only responders (or those tolerating/benefiting) are then randomized to continue active treatment vs. switch to placebo/withdrawal, isolating the drug's ongoing-treatment effect in an enriched population | Pegvaliase-pqpz (Palynziq, PRISM-2) |
| Household/cluster-unit randomization with a designated primary subject | Randomization is assigned at the household/cluster level (e.g., every member of a household receives the same treatment), with one designated "primary subject" per cluster serving as the analysis unit for the primary endpoint | Spinosad (Natroba) |
| Diagnostic-accuracy design layered on a randomized active/placebo-controlled trial structure | A paired within-patient diagnostic-accuracy comparison (e.g., unenhanced vs. contrast-enhanced imaging, blind-read) is the operative efficacy evidence within a trial that is nominally randomized and active/placebo-controlled, with FDA treating the paired comparison (not the between-arm randomized contrast) as the primary evidentiary basis | Sulfur hexafluoride lipid microspheres (Lumason) |
| Historical-control cohort re-selected mid-study after an unblinded interim look | A pivotal historical-control (non-randomized) trial's control cohort is itself re-selected/re-sized after a Data Safety Monitoring Board reviews unblinded interim results and finds the initial control cohort's outcomes "unexpected," raising a data-integrity concern that FDA nonetheless resolves in favor of approval | Defibrotide sodium (Defitelio) |
| Dual-cohort co-requirement design | A single trial pre-specifies two dose- or severity-defined cohorts, both of which must independently reach statistical significance for the trial to be declared positive — a within-trial multiplicity structure distinct from simple secondary-endpoint hierarchy or dose-arm pooling | Avatrombopag (Doptelet) |
| Prespecified factorial combination-product design (per 21 CFR 300.50) | The fixed-dose combination, each individual monotherapy component, and placebo are all randomized from trial inception, specifically to satisfy the FDA regulation requiring demonstration of each component's contribution to a combination product | Fluticasone furoate/vilanterol (Breo Ellipta), Umeclidinium/vilanterol (Anoro Ellipta) |
| Induction-responder re-randomization design (into multiple maintenance-dose arms) | Patients who achieve clinical response during an induction phase (blinded-randomized or open-label) are freshly re-randomized into two or more maintenance dosing arms plus placebo, with the maintenance phase's sample size, endpoints, and multiplicity structure powered and analyzed independently of the induction phase | Vedolizumab (Entyvio, GEMINI I/II) |
| Response-adaptive fixed-interval dosing with criteria-triggered rescue-to-shorter-interval switching | A trial uses a fixed default dosing interval after loading doses, with protocol-defined disease-activity criteria triggering an individualized switch to a shorter interval — distinct from a treat-and-extend design, since the default interval is fixed and only shortens on a defined trigger rather than continuously extending/contracting | Brolucizumab-dbll (Beovu, HAWK/HARRIER) |

## 2. Endpoint / outcome type

| Keyword | Definition | Seen in |
|---|---|---|
| Overall survival (OS) | Time from randomization to death from any cause | PREVAIL (co-primary), FLAURA (key secondary), SOLO-2 (hierarchical secondary), CLL14 (secondary), KEYNOTE-024 (secondary) |
| Progression-free survival (PFS) / radiographic PFS (rPFS) | Time to disease progression (by RECIST or, for prostate cancer, PCWG2/RECIST composite) or death | KEYNOTE-024 (primary), FLAURA (primary), SOLO-2 (primary, PFS-Inv), CLL14 (primary), PREVAIL (co-primary, rPFS) |
| Objective response rate (ORR) / duration of response (DoR) / disease control rate (DCR) | Tumor-shrinkage response-based secondary endpoints | KEYNOTE-024, FLAURA, CLL14 |
| Minimal residual disease (MRD) response rate | Molecular/flow-cytometric measure of disease clearance below a defined threshold | CLL14 (key secondary) |
| MACE composite (3-point / 4-point / 5-component) | Composite of cardiovascular death, MI, stroke (3-point), plus unstable-angina hospitalization (4-point) or plus coronary revascularization (FOURIER's 5-component version) | EMPA-REG, DECLARE-TIMI58, FOURIER, SELECT |
| CV death / HF-hospitalization composite | Heart-failure-specific composite endpoint | PARADIGM-HF (primary), DECLARE-TIMI58 (dual primary) |
| Renal composite endpoint | Composite of eGFR decline thresholds and/or ESRD | PARADIGM-HF (secondary), DECLARE-TIMI58 (secondary, added to closed testing procedure) |
| All-cause mortality (as a distinct secondary) | All-cause death tracked as its own secondary endpoint separate from the composite primary | PARADIGM-HF, SELECT |
| Patient-reported outcomes / HRQoL | Validated patient-reported instruments as secondary/exploratory endpoints | FLAURA (EORTC QLQ-C30/LC13, CTSQ-16), SOLO-2 (FACT-O), PARADIGM-HF (KCCQ) |
| Key secondary endpoint | A secondary endpoint formally elevated for hierarchical alpha-controlled testing (as opposed to a purely descriptive secondary) | FLAURA (OS), FOURIER (3-point MACE), KEYNOTE-024 (OS) |
| Pharmacokinetic/pharmacodynamic activity-threshold endpoint | Primary endpoint defined as the proportion of subjects crossing a pre-specified drug-activity level used as a surrogate for clinical efficacy, rather than a clinical response/survival measure | Erwinaze (serum asparaginase activity ≥0.1 IU/mL) |
| Complete Response (CR) rate — no emesis + no rescue medication (binary composite responder endpoint) | Composite binary endpoint requiring both absence of any emetic episode (vomiting/retching) and no use of rescue antiemetic medication, assessed within a defined post-chemotherapy time window (acute 0-24h, delayed >24-120h, and/or overall 0-120h phase) | Rolapitant/HEC1, Rolapitant/HEC2 (CR in delayed phase, primary; CR in acute and overall phases, key secondary), Rolapitant/MEC (CR in delayed phase, primary) |
| Event-free survival (EFS) | Time from enrollment/randomization to relapse, disease progression, secondary malignancy, or death from any cause — a composite failure endpoint broader than PFS | Dinutuximab |
| Concordance rate (diagnostic/mapping agent vs. reference standard) | Proportion of reference-standard-positive findings (e.g., blue-dye-stained lymph nodes) also detected by the investigational diagnostic/mapping agent; a paired detection-agreement measure, not a clinical-outcome endpoint | Technetium Tc 99m tilmanocept/Lymphoseek |
| Performance-measure analysis without an independent reference standard (verification bias) | A diagnostic-accuracy measure (e.g., PPV, "modified sensitivity") computed without a reference standard truly independent of the investigational test itself, a limitation the FDA reviewer explicitly flags as verification bias | Fluciclovine F 18/Axumin, Gallium Ga 68 dotatate/Netspot |
| Composite CR/CRh (complete remission + complete remission with partial hematologic recovery) rate | A hematologic-malignancy composite response endpoint combining classical complete remission with a partial-hematologic-recovery variant, used as an accelerated-approval surrogate in AML/leukemia trials | Midostaurin-era AML drugs (e.g., gilteritinib, ivosidenib-class trials in this census) |
| Metastasis-free survival (MFS) | Time from randomization to first BICR-confirmed distant (bone/soft-tissue) metastasis or death from any cause — distinct from PFS/rPFS, used in non-metastatic disease settings | Apalutamide (SPARTAN), Darolutamide (ARAMIS) |
| Durable complete response (CR) rate with maintained hematologic remission | A composite responder endpoint requiring a confirmed CR (blood/marrow/imaging criteria) followed by hematologic remission maintained beyond a pre-specified minimum duration (e.g., >180 days) | Moxetumomab pasudotox (hairy cell leukemia) |
| FDA Snapshot algorithm (HIV virologic response) | FDA's preferred definition of virologic success/failure at a fixed timepoint (e.g., HIV-1 RNA <50 copies/mL at Week 48), assigning a single response category based on the last available viral-load value in a defined window, used for the primary regulatory analysis in place of the sponsor's protocol-specified TLOVR (time-to-loss-of-virologic-response) algorithm | Bictegravir/emtricitabine/tenofovir alafenamide (Biktarvy) |
| Continuous psychiatric/neurological rating-scale change-from-baseline endpoint | Primary endpoint defined as change from baseline to a fixed timepoint on a validated clinician- or caregiver-rated continuous scale (e.g., MADRS, RSBQ), analyzed as a continuous outcome rather than a responder/binary endpoint | Vortioxetine (Brintellix, MADRS), Trofinetide (Daybue, RSBQ) |
| Diagnostic PET imaging endpoint against a composite clinical/biomarker reference standard | Sensitivity/specificity of a diagnostic imaging agent assessed against a reference standard built from clinical diagnosis and/or a second biomarker test, rather than a neuropathology-confirmed (autopsy) reference standard | Florquinitau F-18 (Tauklarify) |

## 3. Primary analysis method

| Keyword | Definition | Seen in |
|---|---|---|
| Stratified log-rank test | Log-rank test conducted within randomization strata and combined | KEYNOTE-024, FLAURA, SOLO-2, CLL14 |
| Unstratified log-rank test | Log-rank test ignoring randomization strata (sometimes primary, sometimes a supportive companion to a stratified analysis) | PREVAIL (primary), CLL14 (supportive) |
| Cox proportional-hazards model (stratified or with covariates) | Semi-parametric survival regression used to estimate the hazard ratio and CI | KEYNOTE-024, EMPA-REG, PARADIGM-HF, CLL14, DECLARE-TIMI58, SELECT |
| HR derived from log-rank U/V statistics (not a separately fitted Cox model) | HR and CI computed directly from the log-rank test's score/variance statistics rather than a distinct Cox model fit | FLAURA |
| Kaplan-Meier estimation | Non-parametric survival curve/median estimation | Ubiquitous across all 10 (used wherever a time-to-event endpoint is summarized) |
| Breslow / Efron method for ties | Alternative conventions for handling tied event times within a Cox or log-rank analysis | FLAURA |
| Miettinen-Nurminen method | Method for constructing a CI around a difference/ratio of binomial proportions | KEYNOTE-024 (ORR CI) |
| Brookmeyer-Crowley method | Method for constructing CIs around a Kaplan-Meier median | SOLO-2 |
| Repeated-measures ANCOVA | Longitudinal continuous-outcome model with treatment, region, and timepoint terms | PARADIGM-HF (KCCQ) |
| Score test (Cox) | Hypothesis test based on the Cox model's score statistic rather than a Wald or likelihood-ratio test | SELECT |
| Fisher's exact test | Exact test for association between two binary variables, used for small-sample binomial-proportion comparisons | COMFORT-I (Study 351) |
| Cochran-Mantel-Haenszel (CMH) test | Stratified test for association between two binary variables, combined across stratification levels | COMFORT-II (Study 352, stratified by prognostic risk category), Rolapitant/HEC1, Rolapitant/HEC2, Rolapitant/MEC (stratified by gender) |
| Exact/Clopper-Pearson-type binomial confidence interval | Non-asymptotic CI for a single proportion, commonly used for response-rate or activity-level threshold endpoints in small single-arm studies | Erwinaze |
| One-sided exact binomial test (single-arm ORR hypothesis test) | Formal test of a single cohort's observed response rate against a pre-specified null response-rate threshold, used in lieu of a between-arm comparison in single-arm trials | ERIVANCE BCC/vismodegib |
| Blyth-Still-Casella exact confidence interval | A specific exact-CI construction for a binomial proportion, distinct from (but analogous to) Clopper-Pearson | ERIVANCE BCC/vismodegib |
| Descriptive single-arm response-rate analysis (point estimate + CI, no formal hypothesis test) | Reporting of a response-rate point estimate and confidence interval without a between-arm comparative test or a formal single-proportion hypothesis test, because the trial has no comparator arm and no pre-specified null threshold | Carfilzomib, Ponatinib (PACE) |
| Exact binomial test against a pre-specified performance goal | One-sided hypothesis test of whether a single proportion (e.g., concordance/detection rate, or ORR in a single-arm oncology trial) exceeds a fixed pre-specified threshold, with a two-sided confidence interval reported for context | Technetium Tc 99m tilmanocept/Lymphoseek (concordance rate), Ibrutinib (PCYC-1104-CA, ORR), Rucaparib (ARIEL2), Copanlisib, Acalabrutinib |
| Stratified Wilcoxon rank-sum test with Hodges-Lehmann estimator | Non-parametric stratified test for a continuous/ordinal outcome, paired with the Hodges-Lehmann point estimate and CI for the location shift between arms | Telotristat ethyl (TELESTAR, u5-HIAA change) |
| Jennison-Turnbull repeated confidence interval method | A named method for constructing valid confidence intervals at each analysis of a group-sequential single-arm (or other sequential) binomial trial, accounting for repeated looks at the data | Acalabrutinib (ACE-LY-004) |
| Population pharmacokinetic (PPK) imputation to rescue an invalidated primary dataset | Post hoc population-PK modeling (e.g., with empirical Bayes estimation) used to impute a primary efficacy/PK measure for subjects whose directly observed data were later ruled unusable by a failed bioanalytical validation | Calaspargase pegol-mknl (NSAA imputation) |
| Bayesian posterior-probability decision rule (proof-of-concept gate) | A pre-specified Bayesian threshold (e.g., HR≤X and posterior probability of benefit ≥Y%) used as a gate for whether to proceed with formal testing of an endpoint in a specific cohort | Alpelisib (SOLAR-1, PIK3CA non-mutant cohort gate) |
| Wald confidence interval decision rule for a single activity-threshold responder rate | A single-proportion responder-rate analysis using a normal-approximation (Wald) CI with a pre-specified decision rule (e.g., CI lower bound must exceed a threshold), rather than a p-value hypothesis test or an exact/Clopper-Pearson CI | Asparaginase erwinia chrysanthemi (recombinant)-rywn/Rylaze |
| FDA population-PK modeling to justify a regimen despite a missed primary endpoint | FDA itself conducts population-PK modeling/simulation to support a dosing regimen's adequacy after the observed primary endpoint was not formally met in the studied cohort(s) | Asparaginase erwinia chrysanthemi (recombinant)-rywn/Rylaze |
| Mixed model for repeated measurements (MMRM) with a sandwich variance estimator | Longitudinal continuous-endpoint model (e.g., for patient-reported outcomes) with a robust/sandwich variance estimator, used for key-secondary PRO analyses | Nirogacestat (DeFi trial, PRO secondaries) |
| One-sample z-test against a pre-specified performance goal (per-dose) | A single-arm response rate is tested against a fixed performance-goal threshold separately for each of multiple doses under evaluation, each with its own allocated one-sided alpha | Zongertinib (dose-specific ORR testing) |
| FDA-conducted independent re-adjudication of reported responses | FDA re-reviews/re-adjudicates the sponsor's reported responses using its own timing windows or criteria, potentially changing the response rate and whether a pre-specified CI threshold is still met | Ziftomenib (FDA re-adjudication dropped the reported CR/CRh rate from 21.7% to 18.5%, crossing the pre-specified null boundary) |
| Graphical alpha-propagation method (Maurer-Bretz) | A named graphical approach to multiple testing that allocates and propagates alpha across a pre-specified set of hypotheses (e.g., multiple PFS/OS comparisons across cohorts) via a directed graph of transition weights | Camizestrant (SERENA-6-adjacent design), per Bretz et al. 2009 and Maurer & Bretz 2013 |
| Finkelstein-Schoenfeld hierarchical composite test | A named win-ratio-style method for analyzing a hierarchical composite outcome (e.g., ranking death above hospitalization above a continuous biomarker change) via pairwise patient comparisons | Cardiovascular/metabolic outcome trials with hierarchical composite endpoints |
| ANCOVA with normality-contingent fallback to a non-parametric test (e.g., Wilcoxon) | Pre-specified primary analysis uses ANCOVA if a normality assumption holds, with a pre-specified non-parametric fallback test if it does not | Riociguat (CHEST-1/PATENT-1) |
| Jump-to-reference (J2R) multiple imputation | A named missing-data imputation method for handling treatment discontinuation/intercurrent events, imputing missing post-discontinuation values as if the patient had switched to the reference/control arm | Orforglipron (ATTAIN-1/2) |

## How to use this file when scaling the census

- When writing a new entry, tag it with existing terms from the tables above wherever the underlying method genuinely matches — don't invent a new label for a concept already covered (e.g., always write "stratified log-rank test," never a synonym like "log-rank test with strata").
- Only add a new row when a submission uses a method not already listed. When adding one, write it the same way as existing rows (Keyword | plain-language definition | which submission(s)).
- If a term's definition needs to flex slightly to fit a new use, expand the definition in place rather than forking a near-duplicate term.
- The **[inferred]** / reverse-engineered entries should have any keyword drawn from inference, not confirmed source text, marked so in the entry's Keywords line (see `census.md`) — this taxonomy file itself does not distinguish confirmed vs. inferred usage per drug; that distinction lives only in each entry's Keywords line in `census.md`.
